# M02 — กระบวนการ Data Science บน Microsoft Fabric

อ้างอิง: Microsoft Learn — [Get started with data science in Microsoft Fabric](https://learn.microsoft.com/training/modules/get-started-data-science-fabric/) · สไลด์ M02 · [What is Data Science in Fabric?](https://learn.microsoft.com/fabric/data-science/data-science-overview)

ศัพท์ที่เกี่ยวข้อง: [Data Science](glossary.md#data-science) · [MLflow](glossary.md#mlflow) · [Churn](glossary.md#churn)

## วิทยาศาสตร์ข้อมูลในองค์กรคืออะไร

ไม่ใช่แค่ “ฝึกโมเดลให้คะแนนสูง” แต่คือการค้นหาแบบแผนในข้อมูล แล้วแปลงเป็น**การตัดสินใจที่วัดผลได้** — เช่น ลดของเสีย ลดลูกค้าเลิกซื้อ หรือเพิ่มอัตราซื้อซ้ำ

บน Fabric งานนี้ทำบนข้อมูลที่ถูกกำกับใน OneLake โดยไม่ต้องย้ายออกนอกแพลตฟอร์มทุกขั้นตอน

## 4 ประเภทโมเดลหลัก

| ประเภท | คำถามธุรกิจ | ตัวอย่าง FreshMart |
| --- | --- | --- |
| **จำแนกประเภท (Classification)** | อยู่ในกลุ่มไหน หรือเกิดเหตุการณ์หรือไม่ | ลูกค้าจะเลิกซื้อหรือไม่ |
| **ถดถอย (Regression)** | ค่าตัวเลขเท่าไร | ราคา หรือปริมาณที่คาดการณ์เป็นจุด |
| **จัดกลุ่ม (Clustering)** | จัดกลุ่มโดยไม่มีป้ายกำกับคำตอบ | จัดกลุ่มพฤติกรรมลูกค้า |
| **พยากรณ์อนุกรมเวลา (Forecasting)** | ค่าตัวเลขในอนาคตตามเวลา | ยอดเบเกอรี่สัปดาห์หน้า |

เลือกประเภทจาก**โจทย์และป้ายกำกับที่มี** ไม่ใช่จากอัลกอริทึมที่คุ้นเคย

## วงจร 5 ขั้น

ตาม Microsoft Learn:

1. **นิยามปัญหา** — ทำนายอะไร สำเร็จเมื่อใด (ตัวชี้วัดธุรกิจและเกณฑ์ผ่าน)
2. **ได้ข้อมูล** — เก็บและเข้าถึงผ่าน Lakehouse / OneLake
3. **เตรียมข้อมูล** — สำรวจ ทำความสะอาด สร้างฟีเจอร์ใน Notebook หรือ Data Wrangler
4. **ฝึกโมเดล** — เลือกอัลกอริทึมและค่าตั้งก่อนฝึก แล้วติดตามด้วย MLflow
5. **สร้างข้อเสนอแนะ** — ทำนายเป็นชุด แล้วส่งผลให้รายงานหรือกระบวนการปฏิบัติการ

วงจรนี้**วนซ้ำ** — ถ้าโมเดลดีบนชุดทดสอบ แต่หน้างานใช้ไม่ได้ ให้กลับไปนิยามปัญหาหรือฟีเจอร์ใหม่

## แมปอ็อบเจกต์ Fabric กับขั้นตอน

| ขั้นตอน | อ็อบเจกต์ / เครื่องมือบน Fabric |
| --- | --- |
| ปัญหาธุรกิจ | รายงาน Power BI, ตัวชี้วัด, โมเดลความหมายทางธุรกิจ |
| จัดเก็บข้อมูล | Lakehouse (ไฟล์ + ตาราง), shortcuts |
| สำรวจ / เตรียม | Notebook, Data Wrangler, Spark / pandas |
| ทดลองโมเดล | Experiment (การรันของ MLflow) |
| ลงทะเบียนโมเดล | รายการ ML Model + หมายเลขเวอร์ชัน |
| สร้างคำทำนาย | ฟังก์ชัน PREDICT หรือ `MLFlowTransformer` |
| ใช้ผลลัพธ์ | ตาราง Delta ชั้น Gold, Direct Lake, หรือตั้งเวลารัน pipeline |

## Lakehouse กับ Warehouse สำหรับงานวิทยาศาสตร์ข้อมูล

| | Lakehouse | Warehouse |
| --- | --- | --- |
| จุดแข็ง | Spark, ตาราง Delta, notebook, PREDICT | SQL เข้มข้น, ผู้ใช้รายงานพร้อมกันจำนวนมาก |
| รูปแบบข้อมูล | ไฟล์ + ตาราง | ตารางเชิงสัมพันธ์ |
| แนะนำในหลักสูตรนี้ | **ศูนย์กลางหลักของแล็บ FreshMart** | ใช้เมื่อทีมต้องการ SQL serving ชัดเจน |
